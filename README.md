# Анализатор Жанра

Классификатор музыкального жанра, работающий полностью в браузере — без сервера, без отправки данных.

![Скриншот приложения](https://github.com/user-attachments/assets/11ff8c23-1060-40ef-a643-0258f20f3ede)

---

## Как это работает
 
Загружаете аудиофайл → приложение прямо в браузере извлекает признаки и прогоняет их через нейросеть → вы видите результат. Никакой отправки на сервер, никакого бэкенда.
 
Для этого пришлось решить следующую проблему: Python-библиотека librosa, на данных которой обучалась исходная модель, извлекает признаки иначе, чем JavaScript-аналоги. Пришлось переобучить модель на данных, обработанных уже через JS и Meyda, чтобы она корректно работала на клиенте.
 
---


## Технические решения
 
**Многопоточная архитектура (Web Workers)**
 
Всё тяжёлое — извлечение MFCC и инференс нейросети — вынесено в `audio-analyzer-worker.js`. Основной поток занимается только UI и не блокируется.
 
**Потоковый инференс (async generator)**
 
Трек разбивается на 3-секундные сегменты и обрабатывается последовательно. Каждый сегмент сразу отдаёт результат через асинхронный генератор — вы видите, как диаграмма оживает в процессе анализа, а не ждёте окончания всего расчёта.
 
**Предобработка аудио**
 
- Декодирование через `AudioContext`
- Принудительный ресемплинг в 22 500 Гц через `OfflineAudioContext` (требование модели)
- Преобразование в моно усреднением каналов

**Извлечение признаков**

Параметры MFCC (13 коэффициентов, Hann-окно, FFT 2048, hop 512) повторяют конфигурацию оригинальной модели — это нужно для совместимости с весами при переобучении. Извлечение выполняется через Meyda.

**Визуализация волны (Canvas API)**
 
`WavePlotter` рисует стоблцы формы волны под размер контейнера, вычисляет RMS по каждому столбцу и группирует столбцы на сегменты согласно разбивке трека. По мере анализа каждый сегмент перекрашивается в цвет предсказанного жанра в реальном времени.
 
**Физика пузырьковой диаграммы (Vanilla JS)**
 
`BubbleChart` — диаграмма с анимацией физики пузырьков: гравитация к центру, затухание при трении, определение коллизий, ограничение по границам контейнера. Размер каждого пузыря растёт пропорционально числу сегментов, в которых победил этот жанр.

## Локальный запуск
> **Важно:** приложение нельзя открыть через `file://` — браузер заблокирует загрузку ES-модулей и модели. Нужен любой локальный HTTP-сервер.
1. Клонировать репозиторий
```bash
git clone https://github.com/your-username/music-genre-classifier.git
cd music-genre-classifier
```
 
2. Запустить локальный сервер (нужен из-за ES Modules и CORS)
```bash
npx serve
```

3. Открыть в браузере
```bash
http://localhost:3000
```
